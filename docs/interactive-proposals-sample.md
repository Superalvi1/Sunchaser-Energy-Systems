# Interactive proposal sample — 10 kW hybrid

This reference was transcribed from the supplied SunChaser quotation screenshots. It is
intended as a sales demo and pricing seed, not an automatic commercial approval.

## Base package

| Item | Selection | Reference price |
| --- | --- | ---: |
| Solar array | 16 × 645 W Jinko X20 (10.32 kWp) | PKR 423,120 |
| Hybrid inverter | GoodWe 10 kW | PKR 375,000 |
| Battery | Dyness 51 V, 5 kWh | PKR 225,000 |
| Mounting | Standard roof mounting | Included in package |
| Discounted package total |  | **PKR 1,215,000** |

The reference quotation also includes DC/AC cabling, DB and protection, mechanical
supplies, earthing and lightning protection, installation, transportation, and
survey/design/commissioning.

## Client-editable choices

| Choice | Price adjustment |
| --- | ---: |
| Add/remove one 645 W panel | ± PKR 26,445 |
| Dyness 16 kWh battery | + PKR 360,000 |
| Elevated girder structure | + PKR 110,000 indicative |

The elevated-structure adjustment uses the rounded discounted-package difference in
the supplied 10 kW / 5 kWh references. It should remain subject to site survey and
technical approval because civil and fabrication requirements vary by roof.

## Example client configuration

18 × 645 W panels, GoodWe 10 kW inverter, Dyness 16 kWh battery, and elevated girder
structure:

`PKR 1,215,000 + (2 × 26,445) + 360,000 + 110,000 = PKR 1,737,890`

The interactive proposal must display this as an updated estimate until SunChaser
accepts the technical configuration and issues the final quotation.
